# 🤖 Free WhatsApp Bot for Real Estate Agents

A complete, working WhatsApp chatbot template for real estate agencies, educational institutions, and consultation services in India.

## ✨ Features

✅ **Auto-Reply to Common Questions (10+ pre-written)**
- Hostel cost, stipend, fees, eligibility, documents
- Instant replies 24/7 (even at 3 AM!)
- No agent needed for FAQs

✅ **Smart Lead Qualification (6-step flow)**
- Automatically asks: Name, Course, Budget, Timeline, Location, Phone
- Collects structured data
- Filters serious leads from casual browsers

✅ **Agent Notification System**
- Sends qualified lead data directly to agent's WhatsApp
- Pre-filled information ready
- No manual copy-paste needed
- Agent can call immediately

Student: "Hostel cost kya hai?"
